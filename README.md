# Atlas Unbelievable Studio

Production toolkit for the **Atlas Unbelievable** YouTube channel: animated satellite-map geography episodes,
vertical Shorts cut from them, thumbnails and branding.

Open this repo in Claude Code and ask for an episode or Shorts: the skills in `.claude/skills` hold the workflow.

| Folder | What's in it |
|---|---|
| `engine/ep1/` | The Episode 1 composition (HyperFrames HTML). The scene library to copy from for new episodes. |
| `tools/` | Planning, sharp NASA maps, free media, audio mix, Shorts generator, preview and overlap checks. |
| `episodes/ep1/` | Script, voiceover, transcript, beats, upload text, thumbnails, Shorts plan. |
| `branding/` | Profile picture, banner, logo options, channel text. |
| `sfx/` | Earshot sound-effect kit and music-bed cycle (original, licence-free). |
| `setup/setup.sh` | Installs everything in a fresh session. |

Quick start: `bash setup/setup.sh`
