# Music library

Background music for Atlas Unbelievable comes from the **YouTube Audio Library** (YouTube Studio → Audio library),
filtered to **"Attribution not required"**, instrumental, 2–4 min. Licence: free to use in our YouTube videos, including monetized ones.

File naming: `<mood> - <Track Name>.mp3` with mood one of `mysterious`, `epic`, `fun`, `dark`.
`library.json` records each track's mood, tempo (BPM), length and source.

Mood guide:
- **mysterious**: strange places, hidden facts, "did you know"
- **epic**: big reveals, scale comparisons, intros and outros
- **fun**: quirky borders, funny facts, light Shorts
- **dark**: dangerous places, disasters, tension
